# Frontend Mentor - Rock, Paper, Scissors

A solution for the **Rock, Paper, Scissors** challenge from Frontend Mentor.

## Overview

This project is a browser-based Rock, Paper, Scissors game where users can play against the computer with responsive layouts and interactive UI states.

The application is built using a scalable front-end architecture with React, TypeScript, MobX, and CSS Modules.

## Features

- Play Rock, Paper, Scissors against the computer
- Responsive layout for desktop and mobile devices
- Interactive hover and focus states
- Persistent score system using localStorage
- Modular architecture
- State management with MobX
- CSS Modules styling approach

## Tech Stack

- Vite
- React
- TypeScript
- MobX
- CSS Modules
- pnpm
